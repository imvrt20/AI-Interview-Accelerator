# AI Interview Accelerator 🚀

AI Interview Accelerator is a web application that helps job candidates prepare for interviews by analyzing their resume against a job description and providing personalized mock interview practice.

## ✨ Features

- 📄 Upload and extract text from PDF resumes
- 📝 Enter a job description
- 🎯 Analyze resume and job compatibility
- 💼 Identify matching skills
- 📚 Identify skills that need improvement
- 🤖 Generate personalized interview questions
- 🎤 Practice mock interview questions
- 📊 Evaluate interview answers
- 💡 Get strengths and improvement suggestions
- 📈 Track interview performance

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- CSS
- Axios

### Backend
- Python
- FastAPI
- REST API
- PyPDF2
